# Thallbyssal Sound Design Targets

This file defines the sound goals without copying any commercial product or artist preset.

## Rhythm Default

Goal: tight, low-tuned, clear modern metal rhythm tone.

Important traits:

- Strong pick attack without painful fizz
- Controlled low end
- Clear low-mid weight
- Fast gate that still lets intentional chugs breathe
- Cab default that starts mix-ready and not too bass-heavy
- Enough input gain at default settings for normal DI guitar

Controls that must matter:

- Input gain
- Gate threshold
- Grinder drive/level
- DI Sculpt amount/smooth
- Amp gain/bass/mid/treble/presence/master/output
- Cab low cut/high cut/blend/level

## Drop Tuning Handling

Goal: Drop E, Drop F, Drop A#, Drop C, and similar tunings should stay clear.

Important traits:

- Low string attack remains audible
- Palm mutes do not turn into uncontrolled sub bass
- Transpose remains 100% wet when used
- Low Oct layer is optional and controlled by blend

## Clean And Ambient

Goal: clean parts can become wide, cinematic, and genre-appropriate without living inside the rhythm amp page.

Important traits:

- Separate clean amp EQ
- Space and tone controls
- Reverse and shimmer options
- Stutters/backwards movement for transition effects
- Ring modulation for scream/noise effects

## Preset Categories

Factory presets should cover:

- Tight rhythm
- Heavy breakdown
- Clear pick attack
- Lead cut
- Dark low-tuned weight
- Clean ambient base
- Reverse/stutter FX scene
- Ring scream FX scene

Preset names must be original. They should describe the feel, not reference artists, competitor products, or trademarked names.

## Test Material Needed

Collect or record these DI files for QA:

- Hard palm-mute riff in low tuning
- Fast chug riff
- Open chord rhythm
- Clean arpeggio
- Lead line
- Quiet DI
- Hot DI
- A riff with intentional stops for gate testing
