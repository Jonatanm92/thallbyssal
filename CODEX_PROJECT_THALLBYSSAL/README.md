# Codex Project: Thallbyssal

This folder is the Codex-ready project hub for creating focused agents/threads around Thallbyssal.

Use this folder when you want to start multiple Codex agents without re-explaining the project every time.

## Start Here

1. Open `AGENT_ROSTER.md`.
2. Pick one agent/task.
3. Open the matching prompt in `AGENT_PROMPTS/`.
4. Start a new Codex thread/agent with that prompt.
5. Keep one agent on one branch and one task.

## Project Rules

Every agent must read these root files before doing work:

- `AGENTS.md`
- `CODEX_PROJECT_THALLBYSSAL/AUTONOMY_RULES.md`
- `THALLBYSSAL_PROJECT.md`
- `THALLBYSSAL_FACTORY_QUEUE.md`
- the assigned `TASK_PACKETS/TASK_XXX_*.md`

## Founder Sound Rule

The founder owns the sound.

No agent may modify core DSP, tone behavior, gain staging, cab/IR behavior, preset values, or native audio behavior without explicit founder approval in the current task.

## Autonomy Rule

Safe assigned tasks are pre-approved. Agents should not ask for permission for docs, reports, validators, test-harness work, beta packet work, internal audition pages, task packets, or other allowed-path tasks.

Agents ask only for DSP/core sound changes, destructive writes, public/commercial/legal systems, copyrighted/trademarked assets, external/paid APIs, GUI automation, fake renders, original user-file changes, or work outside their allowed paths.
