# Project Map

## Root Project Files

- `AGENTS.md` - hard rules for all agents.
- `THALLBYSSAL_PROJECT.md` - product/project overview.
- `CHATGPT_PROJECT_SETUP.md` - setup text for ChatGPT Projects.
- `THALLBYSSAL_FACTORY_QUEUE.md` - 24h task queue.
- `TASK_PACKETS/` - exact task instructions.
- `CODEX_PROJECT_THALLBYSSAL/` - this Codex project folder.

## Product Areas

- `native/juce-audio-engine/` - native amp sim, standalone, VST3, offline renderer.
- `AMP_SIM_LAB/` - internal lab/test/report/beta tooling.
- `src/` - React/Vite guitar workflow app.
- `docs/` - supporting docs.
