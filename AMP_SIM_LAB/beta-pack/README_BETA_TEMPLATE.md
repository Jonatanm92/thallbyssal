## Installation Instructions Placeholder

Use these steps only with the private build notes supplied for the beta.

1. Close the DAW before copying plugin files.
2. Copy the beta plugin file to the VST3 folder named in the private build notes.
3. Keep a note of the exact folder used for uninstall.
4. Open the DAW and run a plugin rescan.
5. Test on a copied dry DI guitar track in a non-critical session.
6. Start with DAW/plugin output low, then raise level gradually.
7. If scan or audio fails, stop and fill out the bug report template in `FEEDBACK_FORM.md`.

## Uninstall Instructions Placeholder

1. Close every DAW or standalone host using the plugin.
2. Delete only the beta plugin file from the VST3 folder used during installation.
3. Delete the standalone beta folder only if one was provided.
4. Reopen the DAW and run a plugin rescan.
5. Confirm the beta no longer appears in the DAW plugin list.

Do not delete shared DAW folders, unrelated plugins, original DI files, IRs, presets, or user projects.
